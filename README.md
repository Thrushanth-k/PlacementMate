# PlacementMate

PlacementMate is a full-stack web application designed to help students organize and manage their placement preparation in one place.

It allows users to track placement drives, manage study tasks, monitor progress, maintain notes, and view important dates through a simple and responsive interface.

## 🚀 Live Demo

https://placementmate-frontend.onrender.com

## ✨ Features

- 📊 Placement progress dashboard
- 🏢 Add, edit, delete and track companies
- 🔄 Update placement status
  - Upcoming
  - Attended
  - Selected
  - Rejected
  - Not Going
- 🔍 Search and filter placement companies
- 📅 Calendar for placement drives and study tasks
- 📚 Study task planner
- ✅ Track completed and pending tasks
- 📈 Task completion progress
- 📝 Personal placement notes
- 📱 Responsive design for mobile and desktop
- 💾 Persistent data storage using PostgreSQL
